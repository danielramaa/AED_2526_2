Detailed Description

Web construction and the interference graph built on top of them.

The pipeline is: input Variables -> SubWebs (one per input LiveRange) -> grouping of SubWebs into Webs -> Graph<int> interference graph.

SubWebs are the atomic units. Webs are unions of SubWebs of the SAME variable that share at least one program point. Splitting (T2.3) is implemented by changing the grouping, which is why the SubWeb layer is kept around even when the simpler allocators do not need it.

◆ mergeSubWebs()

std::vector< std::vector< int > > mergeSubWebs ( const std::vector< SubWeb > & subwebs)

Groups SubWebs of the same variable that share at least one program point (union-find).

Each returned group is a list of SubWeb ids that will become one Web.

Complexity: O(V * R^2 * P) in the worst case where V = variables, R = ranges per variable, P = points per range; in practice far less because most variables only have a handful of ranges.

◆ websInterfere()

bool websInterfere ( const Web & a,
const Web & b )

Pairwise interference test using the def/last-use exception described in §2.5 of the handout: two webs do NOT interfere at a shared point X iff one of them is being defined-only there and the other is being last-used-only there.

They DO interfere as soon as any shared point is not such a clean handoff.

Complexity: O(|A.points| + |B.points|) using the points' sortedness.
