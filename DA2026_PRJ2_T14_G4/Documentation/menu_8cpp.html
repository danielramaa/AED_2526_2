Detailed Description

Implementation of the interactive menu and batch entry point.

The algorithmic stages (web construction, interference graph coloring, ...) are not yet implemented; this file wires up the input/output skeleton on top of the parser so that the rest of the team can plug the algorithms in without touching the I/O layer.

Runs the tool in batch mode.

Matches the invocation described. myProg -b ranges.txt registers.txt allocation.txt.

Parses both inputs, attempts the allocation requested by the registers file, writes the result (or an M:-only output) to outputFile, and emits error / status messages to stderr.

Returns
process exit code: 0 on success, non-zero on failure.
