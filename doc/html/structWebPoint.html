Detailed Description

A program point belonging to a (sub-)web, with the def/last-use markers carried over from the input.

When multiple SubWebs are merged into a Web both markers are OR-ed, so a single point can carry isDef=true AND isLastUse=true simultaneously (typical of an i=i+1 pattern).
