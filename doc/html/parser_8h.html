◆ parseRanges()

bool parseRanges ( const std::string & path,
std::vector< Variable > & variables,
std::string & error )

Parses a live-ranges input file (format described in §3.1 of the project handout).

Lines beginning with # and blank lines are ignored. Each non-comment line has the form name: tok1, tok2, ... where every tok is a non-negative integer optionally suffixed with + (start / definition) and/or - (end / last use).

On success variables is filled with one Variable per distinct name (preserving the order of first appearance) and each Variable contains one LiveRange per input line it appeared on.

Parameters
pathPath of the ranges file.
variablesOutput vector, cleared before being populated.
errorOn failure, a human-readable description of the problem.
Returns
true on success, false on I/O or syntax error.

Complexity: O(L) where L is the total number of tokens in the file.

bool parseRegisters ( const std::string & path,
RegisterConfig & config,
std::string & error )

Parses a register-configuration file (format described in §3.4 of the project handout).

Expected entries: registers: N and algorithm: <kind>[, K] where <kind> is one of basic, spilling, splitting, free. Comments (#) and blank lines are tolerated and the order of the two entries is irrelevant.

Parameters
pathPath of the registers file.
configOutput structure, fully overwritten on success.
errorOn failure, a human-readable description of the problem.
Returns
true on success, false on I/O, syntax or semantic error.

Complexity: O(L) where L is the number of lines of the file.
